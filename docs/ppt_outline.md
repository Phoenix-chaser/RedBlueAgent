## 第 12 页：工作② Prompt 迭代与容错

**标题：** 工作②续：Prompt 迭代 + 容错

**迭代过程：**
- 没加"autonomous"→ LLM 每步都问人 → 加上后解决
- 写"many"→ 找 3-4 个就结束 → 换"22"后更彻底
- 不加"Do NOT skip dirsearch"→ 经常跳过 → 加否定强调后解决

**容错：**
- 工具名放错字段 → 自动修正
- JSON 不合法但含"finish"→ 识别为完成
- 无 thought 标签 → 取前 500 字符兜底

**布局：** 上半迭代 3 条，下半容错 3 条

**时间：** 1分钟

## 第 15 页：工作④ 去重

**标题：** 工作④续：漏洞去重

**问题：** 多个工具发现同一漏洞 → 不去重就重复

**规则：** 标题相同 + 组件前缀匹配 = 同一个漏洞

**举例：**
- 已有"/admin"，新发现"/admin/login.php"→ 去重 ✓
- 已有"SQL Injection"，新发现"XSS"→ 不去重 ✗

**归因：** 归因给最早发现的工具

**布局：** 规则 + 2 个例子 + 归因

**时间：** 45秒

## 第 16 页：工作⑤ 安全护栏

**标题：** 工作⑤：安全护栏

**为什么：** AI 自主执行命令，没有边界就不能用

**四层防护：**
- 范围验证：拦截扫描授权外目标
- 危险操作审批：metasploit exploit 等需人确认
- 审计日志：所有操作可追溯
- 命令注入防护：不用 shell=True，防止参数注入

**布局：** 4 个要点，右侧[防护流程图]

**时间：** 1分钟

## 第 17 页：工作⑥ 工具集成

**标题：** 工作⑥：5 个工具集成

**每个工具做了：命令构建 + 输出解析 + 结果合并**

- nmap：XML 解析，脚本白名单防 LLM 幻觉
- nikto：JSON 解析，关键词匹配分 4 级严重程度
- dirsearch：JSON 解析，敏感路径自动标记
- sqlmap：正则解析，batch 模式解决交互问题
- metasploit：正则解析，资源脚本解决交互问题

**统一架构：** BaseTool 接口 → ToolInvoker 路由 → SubprocessExecutor 执行

**布局：** 5 个工具纵向列表 + 底部统一架构一句话

**时间：** 1分钟
