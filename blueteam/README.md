# 提示注入攻击检测器 v2（Prompt Injection Detector）

面向中英文用户输入的提示注入攻击检测系统：**L0 解码还原 → L1 快速通道 → L2 深度专家** 的三级级联架构，含对抗增强训练、堆叠元学习融合、温度校准与成本-精度分析。全程 CPU 可复现（无 GPU / 无外部 API / 无预训练模型下载）。

## 架构

```
                 ┌────────────────────────────────────────────┐
 用户输入 ──────→ │ L0 归一化/解码层                              │
                 │ 零宽清洗·全角折叠·Base64/Hex/URL/ROT13/倒序    │
                 │ 递归解码(深度2)，产出候选明文集合(含原文)          │
                 └──────────────┬─────────────────────────────┘
                                ↓ 对全部候选聚合打分
                 ┌────────────────────────────────────────────┐
                 │ L1 快速通道（亚毫秒）                          │
                 │ 规则(14条正则) ⊕ 混合LR(干净训练) + 引用豁免     │
                 └───────┬─────────────────────┬───────────────┘
                  score≥τ_hi                score≤τ_lo
                  判攻击(直接返回)            判正常(直接返回)
                          └───── 不确定带 → 升级 ─────┘
                 ┌────────────────────────────────────────────┐
                 │ L2 深度专家（数十毫秒，仅约 23% 流量）           │
                 │ 堆叠元学习器：词级/字符/混合LR + 字符TextCNN     │
                 │ + 规则标志（全部为对抗增强训练版）               │
                 └────────────────────────────────────────────┘
```

两级各司其职的设计依据（本项目消融实测）：对抗增强训练以干净召回换鲁棒性
（干净 0.864→0.818，扰动平均 0.795→0.960），因此 L1 用**干净优化的模型**
服务占绝大多数的正常流量，L2 用**见过扰动形态的增强模型**处理不确定样本。

## v2.1 领域适配版（RedBlueAgent 内当前配置）

为支撑红队上下文守卫，训练数据新增「工具输出」良性类（14 模板：nmap/nikto/dirsearch/sqlmap 正常输出行），共 2479 样本。该类既修复了检测器在扫描日志域的分布外误报（守卫误隔离 8→0），也提升了整体判别力：

| 检测器 | AUROC | 召回@安全阈值 | FPR@TPR95 | Hard-FPR |
|---|---|---|---|---|
| 规则基线 | 0.750 | 0.583 | 1.000 | 24.1% |
| 混合特征 LR（增强） | 0.981 | 0.822 | 0.088 | 0 |
| **L0+纵深防御（守卫所用）** | **0.998** | **0.969** | **0.013** | **0** |
| 级联（L1+L2） | 0.990 | 0.965 | 0.013 | 0 |

级联成本：升级率 16.4%，摊销延迟 2.03 ms/条。下文为 v2（独立数据集）的完整记录，方法学与结论不变。

| 方案 | 干净召回 | 扰动平均召回 | 最差扰动召回 |
|---|---|---|---|
| 规则基线 | 0.566 | 0.293 | 0.000 |

## 核心发现

1. **规则基线双向失败**：漏检 43% 未见措辞、对抗性良性误报 25%、混淆攻击下召回归零——单靠关键词/正则做内容安全不可行。
2. **L0 解码层 + 对抗增强 + 级联路由三者合力修复 Base64 规避**：无增强混合模型在该扰动下召回 0.593，级联架构达到 **1.00**。
3. **小数据下深度模型不敌特征工程（结构消融）**：同一增强训练集上，2 层自注意力 Transformer val AUROC ≈0.79，TextCNN（多尺度字符卷积）≈0.90，混合 TF-IDF+LR ≈0.93。深度模型在本架构中的正确定位是**与线性模型误差解耦的第二意见**（堆叠基学习器 / L2），而非单点性能上限。
4. **对抗增强是「鲁棒性-干净性能」的交易**（0.864→0.818 干净召回，0.795→0.960 扰动召回），级联用路由把这个交易变成「全都要」。
5. **校准不是瓶颈**：TextCNN 温度校准后 T≈1.3、测试 ECE 0.125（未校准 0.123）——提升空间在特征与数据侧，不在概率校准侧。

## 方法

### 数据（与 v1 相同协议）
- 126 个种子模板（攻击 64 + 良性 62，中英双语，攻击覆盖 9 类：指令覆盖/角色逃逸/系统提示窃取/数据外泄/工具滥用/编码混淆/分隔符注入/间接注入/伪装授权）× 槽位 × 表面变体 = 2,335 条；
- **模板级不相交划分**（train/val/test 按模板 id），测试集攻击措辞训练时从未出现；
- 对抗性良性样本 25 模板（翻译引用/安全研究/写作引用/关键词重叠）；
- 标注口径：引用攻击语句用于翻译/写作/研究 → 良性；伪装成引用但要求执行 → 攻击。

### 训练
- **对抗增强**：训练集攻击样本以 0.5 概率追加一条随机扰动副本（5 种变换等概率），val/test 不动；
- 线性检测器 C 网格搜索（val AUROC）；TextCNN（kernel 2/3/4/5 × 64 通道，d128）AdamW + val 早停 + 温度校准；
- 堆叠元学习器在验证集基学习器分数上拟合（基学习器未见过验证集 → 天然无泄漏）；
- 阈值协议：L1/L2 分别在各自作用域（全体/带内）的 val 上按 FPR≤10% 选择。

## 目录结构

```
src/
  data_gen.py      模板库 + 模板级划分 + 泄漏自检
  detectors.py     规则/词级/字符/混合/纵深防御（引用豁免）
  deobfuscate.py   L0：归一化 + 递归解码 + 候选聚合扫描
  deep.py          L2 基学习器：自实现字符 TextCNN + 温度校准 + ECE
  perturb.py       5 种对抗扰动（增强与评测共用）
  train.py         对抗增强 + 全模型训练 + 安全阈值（另存无增强对照）

  cascade.py       级联决策带 + 延迟基准

  cli.py           单条预测
```

## 已知局限（诚实声明）

1. **数据为模板构造**：覆盖常见攻击模式但非真实攻击分布，结论应理解为「受控条件下的架构对比实验」；
2. **单轮检测**：未建模多轮对话上下文；
3. **从零训练深度模型受数据规模限制**（2.3k 样本）：预训练多语言模型微调是明确的升级路径，但本项目环境无法下载模型（CPU-only 离线约束）；
4. 级联干净召回（0.919）略低于 L1 单独（0.938）：带内攻击样本被保守的 L2 阈值放过——安全性优先的取舍，放宽 L2 带内阈值可换回召回但推高误报；
5. 温度校准收益接近零（模型已近校准）。
